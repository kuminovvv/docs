# AGENTS.md — backend

**Область:** задачи backend-проекта. Применяйте только разделы для действительно используемых Go, HTTP API, PostgreSQL и других технологий; фактический стек и версии определяет целевой проект. Этот файл не предписывает backend-правила frontend-приложению.

## Контракт выполнения

1. Исполняйте запрос и требования проекта; конфликты кода, спецификации и тестов фиксируйте явно.
2. Изучите API, данные, транзакции, ошибки, concurrency, тесты, миграции и Git-состояние только в затронутой области.
3. Для нетривиальной задачи обозначьте scope, критерии приёмки, риски и план; избегайте ненужных переработок.
4. Сверяйте версию Go, драйверов, HTTP-фреймворка и БД с go.mod/lockfile и официальной документацией. Не копируйте устаревшие API или конфигурации из примеров.
5. Проверяйте права доступа на сервере, валидацию входа, IDOR, транзакционные инварианты, идемпотентность, отмену через context и корректность ошибок. Не ослабляйте собственный verifier.
6. Выполняйте применимые unit/integration/race/fuzz и негативные сценарии на изолированном окружении. Production-системы и реальные пользовательские данные — только по отдельному разрешению.
7. PASS означает выполненную воспроизводимую проверку; SKIP, BLOCKED, FLAKY, таймаут и SETUP_FAILURE не равно PASS.
8. Не раскрывайте секреты и персональные данные. Не выполняйте push/merge/deploy/внешнюю передачу данных без явного разрешения целевого проекта.
9. Завершая, сообщите файлы, команды, результаты, невыполненные проверки и остаточные риски.
