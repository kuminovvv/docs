# 04. React-компоненты

Правила исходного проекта сохранены как **локальные соглашения для React/TS**; не навязывайте их библиотекам и чужим файлам без причины.

- Предпочтительно именованные экспорты и один основной React-компонент на файл. Для Next.js route-файлов сохраняйте необходимые `default` exports.
- Нетрудные контракты размещайте рядом с реализацией; для нескольких связанных типов или общего контракта используйте `types.ts`.
- Суффиксы типов: `*Props`, при необходимости `*Component`, `*Hook`; не создавайте тип-алиас для очевидного компонента только ради шаблона.
- По принятой конвенции проекта деструктурируйте `props` после объявления функции, каждое поле с отдельной строки и default там же, если это улучшает читаемость.
- Порядок блоков: импорты → статические константы → компонент/props → hooks → вычисления/handlers → JSX.
- Статические данные выносите из render, если ссылочная стабильность важна. Helpers без hooks размещайте вне компонента или в `helpers.ts`, когда это улучшает поддержку.
- Импортируйте React hooks/types явно; `import type` для TypeScript-only символов.
- Размер 200–250 строк, 4 уровня JSX, число hooks/handlers из исходных правил — **сигналы для ревью**, не формальные ошибки: разделяйте по ответственности, а не для достижения квоты.

## Пропсы-функции и `Action`

Для `'use client'` **entry file** исходный проект использовал суффикс `Action` (`onCloseAction`) для props-функций, чтобы соответствовать проверке сериализуемости Next.js. Это соглашение о названии, **не механизм сериализации и не Server Action**. Нельзя передавать произвольные клиентские функции через Server → Client границу. Внутри client subtree обычные обработчики допустимы. Проверяйте lint/typecheck и реальную архитектурную границу.

```tsx
export type ModalProps = {
  onCloseAction: () => void;
};

export const Modal = (props: ModalProps) => {
  const { onCloseAction } = props;
  return <button onClick={onCloseAction}>Закрыть</button>;
};
```

Документация: https://nextjs.org/docs/app/api-reference/directives/use-client
