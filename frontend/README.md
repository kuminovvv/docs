# frontend — автономные правила для ИИ-агентов

Готовый к переносу набор правил для проектов со стеком React / TypeScript / Next.js / FSD. Этот каталог — **самостоятельный пакет**: для установки достаточно скопировать его содержимое в корень целевого проекта. Файлы из корня репозитория `kuminovvv/docs` и соседнего каталога не требуются.

- [AGENTS.md](AGENTS.md) — обязательная точка входа.
- [CLAUDE.md](CLAUDE.md) — адаптер для Claude Code.
- [docs/README.md](docs/README.md) — профильные и общие инженерные правила.
- [REVIEW.md](REVIEW.md) — контракт ревью.
- [Verify skill](.claude/skills/verify/SKILL.md) — инструкция Claude Code.
- [docs-check.yml](.github/workflows/docs-check.yml) — опциональный GitHub Actions workflow после переноса в проект.

```sh
python3 scripts/verify_docs.py
```

После копирования заполните профиль проекта по [шаблону](docs/templates/project-profile.md). Поскольку в целевом проекте уже могут существовать `AGENTS.md`, `CLAUDE.md`, `README.md` и workflow, **объединяйте их вручную, не перезаписывая существующие правила без ревью**. Markdown не запускает тесты сам по себе: нужен реальный CI, окружение и команды проекта. Тесты и действия с production без разрешения запрещены.

Содержимое подготовлено из пользовательских правил и практик верификации Claude Code. Проектные логи и секреты в комплект не входят.
