# 01. Загрузка контекста

Начинайте с точки входа задачи, связанного контракта/API, типов, вызывающих компонентов, тестов и runtime-симптомов. Прочитайте локальный `AGENTS.md`, проектный профиль и, если есть, `tasks/todo.md`/`tasks/lessons.md`.

- Не сканируйте всё дерево ради простой задачи. Расширяйте область по зависимостям и фактам.
- Не выбирайте реализацию на основании памяти без чтения фактического кода.
- Не читайте конфиденциальные данные, если не нужны для решения. Не выводите секреты в контекст внешних моделей.
- Фиксируйте версии библиотек и фактическую конфигурацию, прежде чем применять советы из документации.
- Если код, типы, тесты и документированный контракт противоречат друг другу, отмечайте конфликт; воспроизводимое поведение — доказательство текущего состояния, но не автоматическое основание для изменения требований.
